Bot demo

The chat bubble is bottom-right. It answers only from content/meraz.txt — nothing else.

Worth trying, because each probes a different behaviour:

  • "when is meraz" — a straight lookup
  • "is there a registration fee" — a yes/no question, where the first word has to be the truthful answer
  • "can first years take part" — needs inference from the text, not a keyword match
  • "what is the wifi password" — must refuse. A bot that invents answers is worse than no bot.
